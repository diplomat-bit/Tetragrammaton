# Automated Multi-Spec API & XSD Workbench - Generated Artifacts

This directory contains automated TypeScript clients, React components, and schema definitions generated by the Multi-Spec Workbench Generator.

## Directory Layout
- **`data/workbench-catalog.json`**: Comprehensive catalog of all 41 scanned specs, 620 endpoints, and 861 XSD types.
- **`data/specs-summary.json`**: Lightweight summary index.
- **`configs/environments.ts`**: Server base URLs and environment mappings (Sandbox, Production, Mock).
- **`configs/api-clients.ts`**: Typed HTTP client configured with bearer token, API key, and custom header injection.
- **`components/types.ts`**: Generated TypeScript interfaces for data models and request/response payloads.
- **`components/GeneratedApiExplorer.tsx`**: Standalone React interactive endpoint testing component.
- **`components/GeneratedXsdViewer.tsx`**: Standalone React XSD XML schema visualizer & payload generator.

## Usage Example
```typescript
import { createWorkbenchClient } from './configs/api-clients';

const client = createWorkbenchClient({
  baseUrl: 'https://sandbox.api.citibank.com',
  apiKey: 'YOUR_API_KEY',
  bearerToken: 'YOUR_BEARER_TOKEN'
});

const result = await client.request({
  method: 'GET',
  path: '/v1/accounts',
});
console.log(result);
```
